# Tanooki Test Run

A tiny guess-the-number game made by Tanooki Studios **only to test Decomp Buddy's publishing pipeline**
(submission, checks, install steps, malware scan, box art, going live, and the emails that go with them).
It is not a port of any real game, and it's removed from the catalog once a test is done.

## Download

Get the newest build from [Releases](../../releases):

- **Windows:** `TanookiTestRun-windows-x64.zip` - unzip it and run `TanookiTestRun.exe`.
- **macOS (Apple Silicon):** `TanookiTestRun-macos-arm64.zip` - unzip it and run `TanookiTestRun` in Terminal.
- **Linux:** `TanookiTestRun-linux-x64.tar.gz` - extract it and run `./TanookiTestRun`.

No game files are needed. It runs in a terminal window.
